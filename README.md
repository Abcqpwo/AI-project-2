# 寻塔之光 v1.0

**AI 项目二** · 路边摆塔式塔防小游戏 · 1.0 正式版

一条固定车道穿过路肩空地，一波接一波的施工障碍从左侧路口滚进来，你要在路边空地架起处置塔，把它们拦在收费站之前。

在线玩：<https://abcqpwo.github.io/AI-project-2/>

## 玩法

- 固定道路，共 12 波障碍：碎石堆、废轮胎、快滚桶、水泥块，一波比一波多、一波比一波硬。
- 障碍滚到右侧收费站即算漏过，扣通行值；通行值耗尽路段封闭。
- 撑过 12 波即清理完毕。
- 第一波给你 15 秒看清车道、摆好第一座塔；之后每波之间是 8 秒准备时间，面板上能看到下一波的规模，提前加塔。
- 每清完一波有预算奖励，按「立即开波」可以提前开打，用时间换预算。
- 每往后一波障碍血量比上一波高 26%，第 12 波约为第 1 波的 3.9 倍；预算要一直补塔，别全压在开局。
- 难度基准（自动对局实测）：铺满 16 座塔可以零漏怪通关；9 座塔刚好在末波漏 2 个；7 座塔会撑不住第 12 波；5 座塔大约在第 11 波失守。塔位比塔的数量更重要。

## 操作

| 操作 | 效果 |
|---|---|
| 鼠标左键 | 在路边空地建塔（悬停可预览落点与射程） |
| 鼠标右键 | 拆塔，回收七成预算 |
| 触屏点按空地 | 第一次点只显示落点、射程和预算预览；2.5 秒内再点同一格才真正建塔，避免手指误触白花预算 |
| 触屏点按已有的塔 | 选中该塔，面板下方出现「拆除选中塔」按钮 |
| `1` / `2` | 切换警示灯塔 / 水炮桩 |
| `R` | 重开本局 |
| `ESC` | 暂停，再按一次退出回标题 |
| 面板「暂停 / 继续」按钮 | 没有键盘时（手机、平板）替代 `ESC` |
| 面板「声音 开 / 关」 | 开关音效，设置存在本机 |

塔型：

- **警示灯塔**（60 预算）：单点快射，射程约 2.4 格，适合贴着车道连续排布。
- **水炮桩**（110 预算）：溅射伤害并减速 40%，射程约 3.1 格，适合摆在拐角吃多只。

## 结算

- 胜利面板显示完成波次、清理障碍数、剩余预算、本局用时。
- 失败面板显示撑到第几波、清理障碍数、本机最远记录、本局用时。
- 暂停面板显示当前波次、预算、通行值和塔位数。
- 「最远记录」记录的是你打到过的最远波次（死在 3 波就记 3 波），存在浏览器 localStorage，不上传。

## 运行

双击 `index.html` 用浏览器打开即可，单文件、无构建、无本地依赖（仅字体走 CDN，断网时回退系统字体）。手机端支持点选建塔（两次点击确认）、面板拆除、面板暂停和音效开关。

## 实现

原生 HTML + CSS + Canvas 2D，实时 `requestAnimationFrame` 主循环；地图为手绘测绘图风格。

**渲染与性能**

- 整张干草与车道底图在开局时烘焙到离屏 Canvas，每帧和设备像素 1:1 贴回，不做缩放重采样。
- 画布使用不透明上下文（`alpha: false`），底图铺满整屏，因此不需要每帧 `clearRect`。
- 主循环 dt 上限 0.05 秒，切后台自动暂停；障碍、子弹、粒子、命中特效原地压缩回收，路径坐标直接写回障碍对象。
- 塔位用「格子 → 塔」的 Map 索引，悬停、落点检查、预览不再线性扫描塔列表；出怪队列用下标游标，不再逐只 `shift()` 搬数组。
- HUD 只在数值变化时刷新，且限制到 0.1 秒一次；提示文案的测量宽度按文本缓存。

**音效**

- 全部由 WebAudio 现场合成（振荡器 + 包络），不加载任何外部音频文件；首次点击后才创建音频上下文，符合浏览器自动播放策略。
- 射击音按每秒最多 9 次节流，避免多塔齐射时堆出噪声和大量音频节点；浏览器禁用音频时静默降级。

**无障碍**

- 画布提供 `aria-label` 与操作说明的 `aria-describedby`；弹出卡片使用 `role="dialog" aria-modal` 并在打开时聚焦主按钮。
- 波次、通行、预算、清理数通过 `role="status"` 实时播报；提示文案同步写入屏幕阅读器专用 live region。
- 塔型卡片使用 `aria-pressed` 表示选中状态，声音开关同样是 `aria-pressed`；支持 `prefers-reduced-motion` 关闭过渡动画。
