# 寻塔之光

**AI 项目二** · 路边摆塔式塔防小游戏

一条固定车道穿过路肩空地，一波接一波的施工障碍从左侧路口滚进来，你要在路边空地架起处置塔，把它们拦在收费站之前。

## 玩法

- 固定道路，共 12 波障碍：碎石堆、废轮胎、快滚桶、水泥块，一波比一波多、一波比一波硬。
- 障碍滚到右侧收费站即算漏过，扣通行值；通行值耗尽路段封闭。
- 撑过 12 波即清理完毕。

## 操作

| 操作 | 效果 |
|---|---|
| 鼠标左键 | 在路边空地建塔（悬停可预览射程） |
| 鼠标右键 | 拆塔，回收七成预算 |
| `1` / `2` | 切换警示灯塔 / 水炮桩 |
| `R` | 重开本局 |
| `ESC` | 暂停，再按一次退出回标题 |

塔型：

- **警示灯塔**（60 预算）：单点快射，射程约 2.4 格。
- **水炮桩**（110 预算）：溅射伤害并减速 40%，射程约 3.1 格。

## 运行

双击 `index.html` 用浏览器打开即可，单文件、无构建、无本地依赖（仅字体走 CDN，断网时回退系统字体）。手机端也支持点选建塔。

## 实现

原生 HTML + CSS + Canvas 2D，实时 `requestAnimationFrame` 主循环，地图为手绘测绘图风格；最高波次记录保存在浏览器 localStorage。
