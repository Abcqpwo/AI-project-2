# 寻塔之光

**AI 项目二** · 路边摆塔式塔防小游戏

一条固定车道穿过路肩空地，一波接一波的施工障碍从左侧路口滚进来，你要在路边空地架起处置塔，把它们拦在收费站之前。

在线玩：<https://abcqpwo.github.io/AI-project-2/>

## 玩法

- 固定道路，共 12 波障碍：碎石堆、废轮胎、快滚桶、水泥块，一波比一波多、一波比一波硬。
- 障碍滚到右侧收费站即算漏过，扣通行值；通行值耗尽路段封闭。
- 撑过 12 波即清理完毕。
- 第一波给你 15 秒看清车道、摆好第一座塔；之后每波之间是 8 秒准备时间。
- 每清完一波有预算奖励，随手按「立即开波」可以提前开打。
- 每往后一波，障碍血量比上一波更高（约 +20%），后期必须继续加塔才拦得住；预算不算宽裕，别把钱全压在开局。

## 操作

| 操作 | 效果 |
|---|---|
| 鼠标左键 | 在路边空地建塔（悬停可预览落点与射程） |
| 鼠标右键 | 拆塔，回收七成预算 |
| 触屏点按空地 | 第一次点只显示落点、射程和预算预览；2.5 秒内再点同一格才真正建塔，避免手指误触白花预算 |
| 触屏点按已有的塔 | 选中该塔，面板下方出现「拆除选中塔」按钮 |
| `1` / `2` | 切换警示灯塔 / 水炮桩 |
| `R` | 重开本局 |
| `ESC` | 暂停，再按一次退出回标题 |
| 面板「暂停 / 继续」按钮 | 没有键盘时（手机、平板）替代 `ESC` |

塔型：

- **警示灯塔**（60 预算）：单点快射，射程约 2.4 格。
- **水炮桩**（110 预算）：溅射伤害并减速 40%，射程约 3.1 格。

## 结算

- 胜利面板显示完成波次、清理障碍数、剩余预算。
- 失败面板显示撑到第几波、清理障碍数、本机最远记录。
- 「最远记录」记录的是你打到过的最远波次（死在 3 波就记 3 波），存在浏览器 localStorage，不上传。

## 运行

双击 `index.html` 用浏览器打开即可，单文件、无构建、无本地依赖（仅字体走 CDN，断网时回退系统字体）。手机端支持点选建塔（两次点击确认）、面板拆除和面板暂停。

## 实现

原生 HTML + CSS + Canvas 2D，实时 `requestAnimationFrame` 主循环；地图为手绘测绘图风格。

性能上做了几件事：整张干草与车道底图在开局时烘焙到离屏 Canvas，之后每帧只贴一次图；画布用不透明上下文，省掉每帧的整屏清除与透明混合；主循环 dt 上限 0.05 秒，切后台自动暂停；障碍、子弹、粒子、命中特效全部原地压缩回收，路径坐标直接写回障碍对象，不再每帧生成临时对象；HUD 每帧只在变化时刷新，并限制到 0.1 秒一次。普通笔记本与手机上可稳定 60 帧。

窄屏（手机）下开始 / 暂停 / 结算卡片会铺满整个屏幕，按钮不会被矮小的棋盘裁掉。最高波次记录保存在浏览器 localStorage。
